# PROJECT OMEGA: TECH STACK

The technology stack is explicitly chosen for extreme performance, absolute safety containment, and bleeding-edge mathematical verification.

### Primary Programming Languages
*   **Rust**: Core system daemon, concurrency orchestration, memory continuity, containment kernel wrappers, and performance-critical mutation targets. Chosen for fearless concurrency and memory safety.
*   **Python 3.12+**: Neural network orchestration, agent abstractions, poly-cognitive APIs, and rapid prototyping of cognitive models.
*   **C++/CUDA**: Custom tensor operations and execution layers written by the Mutation Engine.

### Formal Provers & Mathematics
*   **Lean 4**: Primary language for the Mathematical Discovery Engine. Used for autonomous theorem proving and verifiable logic checks.
*   **Coq**: Secondary interactive theorem prover for validating containment architectures.

### Concurrency & Distribution
*   **Ray**: Distributed compute framework for running the Poly-Cognitive agents simultaneously across GPU clusters.
*   **asyncio**: Python-level asynchronous event loop for high-throughput I/O.
*   **gRPC / Protocol Buffers**: High-performance, strictly typed internal communication between isolated agents.

### Data & Memory Storage
*   **Neo4j**: Semantic graph database for storing abstract concepts and heuristics (The Abstraction Agent's domain).
*   **Qdrant**: High-performance vector database for rapid episodic retrieval and intuition pattern matching.
*   **RocksDB**: Ultra-fast key-value store for saving continuous state checkpoint tensors.

### Containment & Sandboxing
*   **Firecracker**: AWS-developed micro-VMs. Spawns isolated execution environments in milliseconds for the Truth Verification Core.
*   **gVisor**: Application-kernel running in user-space for defending against autonomous breakout attempts.
*   **Docker**: Standardized containerization for immutable agent environments.

### Analysis & Compilation
*   **Tree-sitter**: Used by the Cognitive Mutation Engine for high-performance Abstract Syntax Tree (AST) parsing and code rewriting.
*   **LLVM**: Compiler infrastructure for compiling autonomously generated C++/Rust routines into hot-swappable dynamic libraries.

### Environment Interaction (Simulation)
*   **Playwright**: Headless browser automation for data retrieval and empirical testing over web APIs.
*   **Numpy / SciPy / PyTorch**: Core mathematical simulation backends for the Imagination Physics Engine.
